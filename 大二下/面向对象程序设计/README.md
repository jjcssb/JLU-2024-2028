这门课给分当然非常好啊，朱老师一整个海底捞，几乎写满就挂不了，也是送了我一个96哈。（从我个人角度来说：这门课开给大一学生有点不合时宜，大家的代码量都没上去，根本领悟不到oop的思想，对我这种大二补修的可能会占点便宜，同时这也可能是为什么海底捞的原因吧）

第一大题 判断题（错的要讲理由，基本上只有1个或者2个是对的） 10个 20分 这一题也是没有任何办法捞人的题，能不能满绩也大概率看第一题做得怎么样

第二题开始就是论述题那种了 印象中考了:‘<>’这个符号的用法，值空间类型代码的动态怎么理解，公司和子公司设计，虚函数虚机制的代码的输出结果，类构建，构造析构赋值成员函数等等，还有stl中vector等一些常见用法要会用,里面代码可能会涉及。

还有可能会有小作文题：比如24级考的是谈软件工程专业和ai时代啥的 25级考的是写一个作文一样的，要用到他给的一堆词汇：里面有软件工程 ai具身智能什么的，总之有点文学素养就可以轻松过关了
