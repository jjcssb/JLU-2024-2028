作为408考纲中的关键课程，同时在我心目中为数不多在大学教学中会对学生有收益的课程，同时会遇上在我心目中最好的老师朱老师的一门课程，我的评价直接给到一个夯！

这门课和程序设计基础一样没有任何捷径，唯有练习

个人建议：从最开始就认真看朱老师课件，吃透每一个知识点，多做题

此课成绩构成比较复杂：

平时分15分（包含上课签到作业随堂测试等，但一般比较容易得，也尽量得满）

 pta练习7分（注意不要抄袭，尽量不要使用ai，多锻炼自己的能力）， 

 第一次上机考试7分（共三题，全部都是pta练习题，也就是你要吃透每一次作业题，这分就能拿下），

第二次上机考试21分（共三题，满分100分。

​					第一题签到题绝大多数人都能答上，占30分。

​					第二题，已知中根序和层序重建二叉树，再后根序输出，占50分。

​					第三题，图问题，占20分，输出各点间最短路径，多少条相同最短路径，最短路径上能得到police的最多个数（题目给出各个点police数） （我个人用floyd和n次dij都尝试了一遍，一个点都没有通过，均显示超时，可能需要时间复杂度更低的处理方式）

）

期末笔试 50分： 其实考的很难，多做做王道的题或者是考研真题找找手感，最后的程序题不会写也不要空，多写思路多写注释，让老师有捞你的空间。

注：

根据朱老师描述，计软两院满绩率约6% 挂科率约20% 

从我个人体感而言：应该算是整个大二上最难的课程，希望各位学弟学妹们多练习，为未来早做准备
