网上有哈工大李老师的课程，也有很多人推荐，和软工用的书是一致的可以放心食用（但我听他的课会很困...所以大家自己鉴别吧）

校内奶龙老师（曲老师）的课很值得听，如果跟我一样听哈工大老师会困的话建议听她的

学习通里应该会有一套往年题（我们是2023级的题），其中大题必考两个（最后曲老师肯定会提的），但24级的试卷的量比23级要大，做好心理准备即可

简答题也是从题库中抽，但从24级考察来看并非完全在题库范围内，可能会有一两个题目是考察理解的（题库即为计组解答那个word文件，学习通里应该会发题目，可以自行对照看题目有没有变化）
